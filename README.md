#  Retail: Sales and Inventory Copilot

This repository contains the initial foundation for **PS03 — Retail: Sales and Inventory Copilot** for NexusTiQ24.

## Overview
This is the initial project skeleton and foundation setup. It provides the minimal FastAPI structure required to start building the retail sales and inventory copilot application.

## Startup Command
To start the application from the repository root, run:

```bash
python app.py
```

## Local Access
Once started, the complete application is served at:
- **Application URL**: [http://localhost:8000](http://localhost:8000)
- **Health Check Endpoint**: [http://localhost:8000/api/health](http://localhost:8000/api/health)
